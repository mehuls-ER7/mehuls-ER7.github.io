Python is a great first language because the code reads almost like English. The trick is not to watch endless videos, but to build small things from day one.

## Step 1: Learn the basics in one week

Focus only on variables, if/else, loops, lists and functions. Do not go deeper yet.

## Step 2: Build tiny projects

- A number guessing game
- A to-do list in the terminal
- A script that renames files in a folder

## Step 3: Practice every day

Thirty focused minutes daily beats a five-hour weekend binge. Keep a small streak going and increase the difficulty slowly.
